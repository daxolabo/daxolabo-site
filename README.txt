DÉPLOIEMENT SIMPLE SUR VERCEL
1. Décompresser cette archive.
2. Créer un dépôt GitHub et y téléverser index.html, vercel.json et le dossier public.
3. Dans Vercel : Add New > Project > Importer le dépôt.
4. Pour ce site statique, aucun framework n'est nécessaire.
   Build Command : laisser vide
   Output Directory : .
5. Cliquer sur Deploy.
